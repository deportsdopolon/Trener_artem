# Тонус — дневник персонального тренера

Веб-приложение (PWA): открываете в Safari и добавляете на экран «Домой» — работает как обычное приложение. Данные хранятся **только на iPhone** (localStorage), не на сервере.

**Основная ссылка:** https://deportsdopolon.github.io/trener_artem/

## Установка на iPhone

1. Откройте ссылку в **Safari** (не в Telegram/Chrome — именно Safari)
2. Нажмите **Поделиться** (квадрат со стрелкой вверх)
3. Выберите **«На экран "Домой"»**
4. Нажмите **Добавить**

Готово — иконка «Тонус» появится на рабочем столе. Клиенты, веса и история остаются на этом телефоне.

## Возможности

- Неделя: фамилия клиента + время занятия
- Тренировка дня: фокус (руки/ноги/спина), упражнения, подходы вес × повторы
- 37 упражнений в справочнике + свои
- История прошлых весов и «Повторить подходы»
- Замеры клиента: руки, талия, ягодицы, ноги, плечи (см) и вес (кг), история с датами
- Офлайн после первого открытия

## Разработка

Нужен Node.js 22.12+ (либо 20.19+) и npm.

```bash
npm install
npm run dev
```

Dev-сервер: `http://localhost:5173/Trener_artem/`

## Сборка и публикация (GitHub Pages)

Как у ежедневника: готовое приложение лежит в `docs/`.

```bash
npm run build
```

Публикуется с ветки `main`, папка `/docs`. После пуша в `main` страница доступна по ссылке выше.

## Использование

- **Неделя** открывается первой. Стрелки переключают недели. «+» — новое занятие (клиент, дата, время).
- Нажмите на клиента → тренировка дня: фокус, упражнения, подходы.
- **Замеры** слева от имени в тренировке — ввод с запятой или точкой; каждое сохранение добавляет запись с текущей датой. Последние значения подставляются в форму, прошлые видны ниже. Хранение на устройстве в `tonus-data-v1`, отдельно по клиентам.
- **История** — прошлые записи; «Повторить подходы» копирует прошлые веса.
- **Клиенты** / **Упражнения** — справочники с добавлением и правкой.

## Хранение

Ключ `tonus-data-v1` в localStorage браузера/PWA на устройстве. Синхронизации между телефонами нет. Очистка данных сайта в Safari удаляет записи.
