# Тонус — дневник персонального тренера

Мобильное PWA на React + TypeScript + Vite. Русский интерфейс с крупными кнопками, спокойной тёмной палитрой и safe-area для iPhone. Основной размер — 390 × 844; на больших экранах интерфейс ограничен шириной 600 px.

## Запуск

Нужен Node.js 22.12+ (либо 20.19+) и npm.

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Готовое приложение находится в `dist/`. Для установки PWA разместите содержимое на HTTPS-сервере в корне домена (localhost также поддерживается). Service worker включается только в production-сборке. На iPhone откройте приложение в Safari, нажмите «Поделиться» → «На экран Домой». После первого успешного открытия production-версии приложение работает без сети.

## Использование

- **Неделя** открывается первой. Стрелки переключают недели, «Текущая неделя» возвращает к сегодняшней. Нажмите «+» рядом с днём, выберите клиента или создайте нового, укажите дату и время. Карандаш изменяет или удаляет слот.
- Нажмите на фамилию в расписании, чтобы открыть тренировку на этот день. Заполните фокус дня, выберите упражнения, добавьте подходы и введите вес и повторения. Допускаются десятичные веса с точкой или запятой. Записи сохраняются при каждом изменении.
- Для каждого упражнения отображается последняя предыдущая тренировка этого клиента с ним. «Повторить подходы» переносит прошлые значения в текущую тренировку (заменяя текущие подходы этого упражнения). Вкладка «История» открывает предыдущие записи, включая занятия без слота в расписании.
- **Клиенты**: добавление, переименование, удаление и открытие тренировки на сегодня. Удаление клиента удаляет его расписание и историю после подтверждения. Удаление отдельного слота сохраняет тренировку.
- **Упражнения**: поиск, добавление, переименование и удаление. Предустановлены все 37 упражнений из задания. Удаление из справочника сохраняет ранее записанные упражнения в истории.

## Хранение и ограничения

Все данные хранятся в localStorage браузера (`tonus-data-v1`), переживают перезагрузку и не отправляются на сервер. Пустая установка не содержит вымышленных клиентов или занятий. Резервного копирования и синхронизации между устройствами нет: очистка данных сайта удаляет записи. Safari и установленное PWA могут использовать отдельное хранилище — ведите записи в одном выбранном варианте.

Одна запись тренировки соответствует паре «клиент + дата»: два слота одного клиента в день открывают одну тренировку. Вес и повторения неотрицательны; поля можно оставить пустыми. Изменения старых тренировок также сохраняются. Для обновления офлайн-оболочки при выпуске новой версии измените `CACHE` в `public/sw.js`.

## Проверка сценариев

```bash
npx playwright install chromium
npm run test:e2e
```

Проверка запускает production-сборку на порту 4175 и проходит создание / изменение / удаление клиентов, слотов и упражнений, запись подходов, историю, сохранение после перезагрузки и офлайн-запуск на мобильном viewport 390 × 844. Тестовые данные создаются в изолированном браузерном контексте.
